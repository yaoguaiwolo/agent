# Agent 学习笔记

## Agent 的三件套

Agent 由三样东西组成：工具（Tool）、记忆（Memory）、循环（Loop）。
工具是普通 Python 函数加一份说明书；记忆是一个列表，每次请求原样重发给模型；
循环是反复思考、调用工具、把结果塞回记忆，直到给出最终回答。
LLM 从不执行任何东西，它只负责出主意，动手的是我们写的代码。

## 上下文长度管理

记忆列表不能无限增长，否则每轮发送的 token 会暴涨。
我们用了两招：滑动窗口只保留最近的消息；自动摘要把旧消息压缩成一段摘要。
压缩触发线是 MAX_KEPT_MESSAGES，压缩后保留 SUMMARY_KEEP_RECENT 条最近原文。
摘要本身超过 MAX_SUMMARY_CHARS 字时会再压一遍，防止滚动摘要越滚越大。
工具调用请求和它的结果是一对，切分记忆时永远不能把这一对拆散，否则接口报 400。

## 保险丝的作用

单次提问最多允许 MAX_TOOL_ROUNDS 轮工具调用。
如果没有上限，模型可能在工具报错后无限重试，程序永不返回，费用持续燃烧。
保险丝把最坏情况从"无限"变成"最多 N 轮"。

## 重要的设计分工

凡是能写成规则的活，写进代码；需要理解意思的活，才叫 LLM。
数数、切割、流程控制归代码；摘要、判断信息重要性归模型。
